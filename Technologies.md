# Technologies Used

The Expense Tracker project utilizes a modern (for its target environment) and robust stack for desktop application development:

- **Programming Language**: C# (C-Sharp)
- **Framework**: .NET Framework 4.7.2
- **UI Technology**: Windows Forms (WinForms)
- **Data Interchange Format**: JSON (JavaScript Object Notation)
- **Library for JSON**: `System.Web.Script.Serialization` (JavaScriptSerializer)
- **Development Environment**: Visual Studio
- **Version Control**: Git
