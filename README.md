# Expense Tracker

A simple and intuitive Windows Forms application designed to help users track and manage their daily expenses efficiently.

## Features

- **Add Expenses**: Easily record new expenses with details such as amount, category, description, and date.
- **View Expenses**: All recorded expenses are displayed in a clean, tabular format.
- **Update Expenses**: Modify existing expense entries if details change.
- **Delete Expenses**: Remove unwanted or incorrect expense records.
- **Search Functionality**: Quickly find specific expenses by searching for their amount.
- **Total Calculation**: Automatically calculates and displays the total sum of all expenses currently in the list.

## Prerequisites

To run this project locally, you will need:

- **Visual Studio**: 2017 or later is recommended.
- **.NET Framework 4.7.2**: Ensure this version of the .NET Framework is installed on your machine.

## Getting Started

Follow these steps to set up the project on your local machine:

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   ```
   *(Alternatively, download the source code as a ZIP file and extract it.)*

2. **Open the Project**:
   - Navigate to the project folder.
   - Double-click the `Expense Tracker.sln` file to open the solution in Visual Studio.

3. **Build the Solution**:
   - In Visual Studio, go to the **Build** menu and select **Build Solution** (or press `Ctrl+Shift+B`).

4. **Run the Application**:
   - Press **F5** or click the **Start** button in Visual Studio to launch the Expense Tracker.

## How to Use

1. **Adding an Expense**:
   - Enter the amount (numeric value).
   - Select a category from the dropdown menu.
   - (Optional) Provide a brief description.
   - Select the date of the expense.
   - Click the **Add** button.

2. **Updating an Expense**:
   - Click on an expense in the list to select it.
   - The details will populate the input fields.
   - Modify the details as needed and click the **Update** button.

3. **Deleting an Expense**:
   - Select an expense from the list.
   - Click the **Delete** button.
   - Confirm the deletion when prompted.

4. **Searching**:
   - Enter an amount in the search box and click **Search** to filter the list.
   - To clear the search and view all expenses, clear the search box and click **Search** again.
