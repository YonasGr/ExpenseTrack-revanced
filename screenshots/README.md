# Screenshots Guidance

To complete your project documentation, please follow these steps to capture the required screenshots. Once captured, save them in this folder with the specified filenames.

## Required Screenshots

1.  **main_interface.png**
    - Open the application.
    - Capture the entire window showing the empty or populated grid.
2.  **add_operation.png**
    - Fill in the expense details (Amount, Category, etc.).
    - Click the **Add** button.
    - Capture the interface showing the success message box or the new entry in the grid.
3.  **update_operation.png**
    - Select an existing expense in the grid.
    - Change one of its details (e.g., the amount).
    - Click the **Update** button.
    - Capture the interface showing the updated record.
4.  **delete_operation.png**
    - Select an expense in the grid.
    - Click the **Delete** button.
    - Capture the "Confirm Delete" dialog box before clicking "Yes".
5.  **search_operation.png**
    - Enter a value in the search box.
    - Click the **Search** button.
    - Capture the grid showing the filtered results.

## How to capture on Windows
- Use **Win + Shift + S** to open the Snipping Tool.
- Select the application window.
- Save the file as a `.png` in this directory.
